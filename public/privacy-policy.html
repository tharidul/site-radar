1. Introduction

This Privacy Policy describes how SiteRadar (the "Extension") handles information during its operation. This policy is written to accurately reflect the Extension's actual implemented behavior — not aspirational practices.

2. Extension Description

SiteRadar is a browser extension that inspects the currently active website at your explicit request. It evaluates the site's security posture, performance characteristics, SEO metadata, accessibility compliance, and web development best practices. It generates evidence-based findings, severity-classified issue reports, category scores, and downloadable audit reports.

3. Information We Collect

3.1 Information We Do NOT Collect

The Extension does not collect:

  • Your browsing history
  • Cookies from any website
  • Authentication credentials or passwords
  • Form field values or user-submitted data
  • Personally identifiable information about website visitors
  • Financial information
  • Local storage or session storage contents of inspected websites
  • Analytics or telemetry about how you use the Extension
  • Error logs transmitted to any server
  • Any information from websites you visit that you do not explicitly inspect

3.2 Information Processed During Inspection

When you explicitly start an inspection, the Extension accesses the following from the tab you are currently viewing:

Always accessed (local processing only, never transmitted):

  • The URL of the active tab you chose to inspect
  • The page title
  • HTML document structure and DOM elements (meta tags, headings, links, images, scripts, stylesheets, form elements)
  • Structural metadata about forms — field types, autocomplete attributes, whether fields have values (not the values themselves)
  • External resource URLs referenced by the page
  • HTTP response headers returned by the server

Optionally accessed (only when you enable consent for specific providers):

  • The resolved IP address of the inspected domain (sent to ipapi.co for ASN/geolocation lookup)
  • The hostname of the inspected domain (sent to a DNS-over-HTTPS provider)
  • The domain name of the inspected site (sent to crt.sh for Certificate Transparency query)

4. How Website Information Is Processed

4.1 Local Processing

The vast majority of inspection work happens entirely within your browser. DOM analysis, accessibility testing (using the bundled axe-core library), performance analysis, SEO analysis, best-practice checks, and score calculation all run locally. No page content is transmitted to any server during local analysis.

The Extension makes a background HTTP HEAD request to the target URL to retrieve response headers for security analysis. This is a direct request from your browser to the target website — no third-party server is involved.

4.2 Deep Crawl Mode

In "Deep" mode, the Extension fetches additional pages from the same domain you are inspecting (maximum 50 pages by default). These are direct requests from your browser to the target website. The crawled content is processed in memory only. The Extension identifies itself with the User-Agent string WebsiteIntelligenceBot/1.0 during crawl fetches.

6. Local Storage

The Extension writes only the following minimal configuration to your browser's local storage:

KeyValuePurpose
theme "dark" or "light" Remembers your preferred color theme
crawlLimits max pages, depth, concurrency, timeout Remembers your deep crawl configuration

Audit results, findings, scores, inspection reports, URLs, and website content are never written to disk or persistent storage. They exist strictly in temporary service worker RAM during your active session. When you close your browser, navigate away from the audited domain, or click "Clear", all inspection data is immediately and permanently destroyed.

7. Third-Party Services and Integrations

The Extension bundles the axe-core accessibility testing library (by Deque Systems). This library runs entirely within your browser and makes no network requests. No other analytics platforms, advertising networks, or tracking services are included or integrated.

8. Data Sharing Practices

We do not:

  • Sell any information to third parties
  • Share inspection results with any party
  • Use inspection data for advertising purposes
  • Use inspection data for user profiling
  • Share data for any purpose unrelated to the Extension's audit function

The only information that leaves your device is the information transmitted to the optional external intelligence providers listed in Section 5, and only when you have explicitly enabled each provider.

10. Data Deletion & Automatic Purging

  • Automatic deletion on browser close: When your browser is closed, all in-memory audit results, URLs, and session data are immediately erased by design.
  • Automatic deletion on navigation: When you navigate to a different website, previous audit data is cleared and never displayed on the new site.
  • Manual reset: Click the reset icon button in the Extension header at any time to instantly flush all in-memory audit results.
  • Reset crawl configuration: Click "Reset" in Extension Settings.
  • Revoke external consent: Click "Disable all" in Settings > External Intelligence Opt-In.
  • Remove all Extension data: Uninstall the Extension. This completely removes the extension and all stored preferences.

11. Data Security

The Extension implements the following security measures:

  • Secret redaction: Before any page data is processed or included in a report, the Extension automatically redacts API keys, JWT tokens, AWS keys, GitHub tokens, Stripe keys, Bearer/Basic authentication headers, credit card numbers (Luhn-validated), and passwords in URLs.
  • Private network guard: The Extension will not make requests to private IP addresses, loopback addresses, or reserved network ranges.
  • DNS rebinding protection: DNS responses resolving to private IP addresses are blocked before any request is made.
  • Scheme validation: The Extension will not inspect chrome://, about:, file://, or other internal browser pages.
  • Consent gating: External network lookups cannot be triggered without your explicit opt-in for each provider.

12. Permissions and Their Purposes

The content script is registered to run on all URLs so it can respond when you audit any website you choose. The script is passive — it performs no actions until you explicitly start an inspection from the popup.

13. User Rights and Privacy Choices

  • The Extension only inspects the site you explicitly choose to audit.
  • Each external intelligence provider can be individually disabled in Settings at any time.
  • Click "Clear" at any time to remove all inspection data from memory.
  • Exported reports go to your device only — you control when and whether to export.
  • Uninstalling the Extension removes all stored configuration data.

14. Children's Privacy

The Extension is intended for web developers and security professionals. It is not directed at children under 13 and does not knowingly collect information from children.

15. Limited Use Compliance

The Extension's access to and use of information obtained through inspecting websites is limited to providing the website audit features visible to the user. The Extension does not use website content for unrelated purposes, does not transfer data to third parties except as described in Section 5 (optional, consent-gated), does not use data for creditworthiness determination, and does not sell user data.

This complies with the Chrome Web Store User Data Policy Limited Use requirements.
